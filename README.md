# Respirator Guide v2

Which mask to wear, how much each one lets in, and how to get a seal that works: https://sofyaleb.github.io/respirator-guide-v2/

The main page has an interactive mask comparison, a situation guide, four ideas behind protection factors, fit, what to buy, equivalent names and sources. `time.html` is the exposure clock and `pandemic.html` explains how respirators could stop a worst-case pandemic.

`shared.js` holds the mask data, the models to look for and the animated face drawing.

The first version is at https://sofyaleb.github.io/respirator-guide/.
